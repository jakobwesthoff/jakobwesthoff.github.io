# Vendored icons: Dashboard Icons

The SVG icons in this directory are copied verbatim from the
[Dashboard Icons](https://github.com/homarr-labs/dashboard-icons) project.
They are used here because the corresponding brands are not available in any
Iconify collection (unlike, e.g., Printables, which is pulled from Iconify's
`simple-icons` set at build time and therefore not vendored).

- **Source:** <https://github.com/homarr-labs/dashboard-icons>

local icons to `currentColor`, so the icon inherits the surrounding text
color without the source SVG being edited here.
