# Vendored icons: selfh.st/icons

The SVG icons in this directory are copied verbatim from the
[selfh.st/icons](https://github.com/selfhst/icons) project. They are used
here because the corresponding brands are not available in any Iconify
collection installed in this project.

  `LICENSE` file in this directory)
- **Retrieved from commit:** `02dd039d62a8e7132f4828e69162fca30bd43bb5`

## Files

| File | Upstream path | Referenced in code as |
| --- | --- | --- |
| `snapmaker-dark.svg` | `svg/snapmaker-dark.svg` | `local:selfhst/snapmaker-dark` |

The files are unmodified. The `-dark` variant is the single-colour one; at
build time `astro-icon` recolors monochrome local icons to `currentColor`,
so the icon inherits the surrounding text color without the source SVG
being edited here.
